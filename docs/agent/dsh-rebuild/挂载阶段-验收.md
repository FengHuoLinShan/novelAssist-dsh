## 实现期发现(进 ADR/契约, 不阻塞)

1. cordis 的 inject 门禁按 fiber 生效, 工具执行可能在其他 fiber 下跑 →
   统一 `svc(ctx, name)`(ctx.get)读取, 缺失由适配器降级/fail-closed
   (dsh/src/ctx.ts + dsh/README.md 工程约定 1)。
2. `--patch` 覆盖层格式 = 顶层 YAML **数组** of PatchOptions(`- insert: [...]`)。
3. 跨树加载插件必须与 CLI 同 node_modules 树, 否则双 cordis 实例破坏 Service
   symbol 注册(CLI e2e 用「拷入安装树 + 绝对路径」规避; 发布后 `dsh plugin add`
   天然满足)。
4. domain zod 校验发生在 durable 读边界(重开时), 写入期不即时拒绝(测试按此断言)。
